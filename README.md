# Reisetagebuch

Ein Reiseblog im Kritzel-Tagebuch-Stil für GitHub Pages.

- `index.html` – die Webseite (alles auf einer Seite)
- `_posts/` – die Einträge, eine Datei pro Eintrag
- `bilder/` – die Fotos
- `_config.yml` – Titel und Untertitel
- `VORLAGE.md` – Vorlage für neue Einträge
- `ANLEITUNG.md` – So schreibt man einen neuen Eintrag

Die drei Einträge in `_posts/` und `bilder/beispiel-lyon.svg` sind Beispiele und können gelöscht werden.

**Veröffentlichen:** Settings → Pages → Source „Deploy from a branch“ → Branch `main`, Ordner `/ (root)` → Save.
